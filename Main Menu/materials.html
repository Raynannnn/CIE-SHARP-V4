CHAPTER 02

C# Program Structure

A simple C# program

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, C#");
    }
}

A C# program is organized into different parts. The example above contains a namespace import, a class, a Main method, braces, and a statement.

1
using System;

Allows the program to use types from the System namespace.

2
class Program

Defines a class named Program.

3
{ }

Braces group the statements that belong to a class or method.

4
Console.WriteLine(...);

Represents a statement that ends with a semicolon.

CHAPTER 03

Basic Syntax Rules

Rule 01: End statements properly

CORRECT 
int score = 10;
INCORRECT 
int score = 10

Many C# statements use a semicolon at the end. Missing the semicolon can cause a syntax error.

Rule 02: Match braces

if (score > 0)
{
    Console.WriteLine("Valid score");
}

An opening brace should have a matching closing brace. Proper indentation makes the beginning and end of a block easier to see.

Rule 03: Follow C# capitalization

CORRECT 
Console.WriteLine("Hello");
INCORRECT 
console.writeline("Hello");

C# is case-sensitive. Capitalization matters when writing identifiers such as Console and WriteLine.

CHAPTER 04

Syntax Formatting

Formatting is more than making code look nice

Good formatting makes the structure of a program easier to read and helps learners locate syntax mistakes.

01

Indentation

Statements inside a block should be indented consistently.

02

Spacing

Use readable spaces around operators and between parts of a statement.

03

Braces

Keep opening and closing braces aligned so blocks are easy to identify.

04

Line Breaks

Place separate statements on separate lines for clearer code structure.

Formatted example

class Program
{
    static void Main()
    {
        int score = 90;

        if (score >= 75)
        {
            Console.WriteLine("Passed");
        }
    }
}
CHAPTER 05

Code Examples

Example 01: Variable declaration

int age = 20;
string name = "Alex";
double grade = 95.5;

Each declaration is written as a statement and ends with a semicolon.

Example 02: Conditional statement

int score = 85;

if (score >= 75)
{
    Console.WriteLine("Passed");
}
else
{
    Console.WriteLine("Failed");
}

The braces clearly separate the statements belonging to each condition.

Example 03: Spot the formatting problem

if(score>=75){
Console.WriteLine("Passed");
}

The code may be difficult to read because spacing and indentation are missing. Formatting it clearly improves the visibility of the program structure. 

if (score >= 75)
{
    Console.WriteLine("Passed");
}
