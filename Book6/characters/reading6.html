LEARN THE SPELL • 01

Understanding Methods

A method is a named block of code designed to perform a particular task.

Methods help organize programs by dividing larger problems into smaller sections. Instead of writing the same instructions repeatedly, a programmer can place them inside a method and call the method whenever it is needed.

ARCANE FACT

A method lets a spell be cast the same way every time it is called, without rewriting the incantation.

LEARN THE SPELL • 02

Declaring a Method

A method declaration defines the method's name, return type, parameters, and instructions.

A method can be designed to perform a specific action, such as displaying information, calculating a value, or processing data. 

static void CastSpell(){
    Console.WriteLine("A spell is cast!");
}
Using descriptive method names helps make a program easier to understand.
LEARN THE SPELL • 03

Calling a Method

A method does not perform its task simply because it has been declared. It needs to be called or invoked.

Calling a method tells the program to execute the instructions contained within that method. 

CastSpell();
REMEMBER

A method can also be called multiple times whenever the same operation is required.

LEARN THE SPELL • 04

Parameters and Arguments

Methods can receive information through parameters. A parameter is a variable defined in the method declaration that represents information the method expects to receive.

An argument is the actual value provided when the method is called. 

static void CastSpell(string spellName){
    Console.WriteLine(spellName + " is cast!");
}

CastSpell("Fireball");
Using parameters allows one method to work with different values instead of creating separate methods for every situation.
LEARN THE SPELL • 05

Return Values

Some methods perform an action without producing a value, while others calculate and return a result.

A method that returns a value specifies the appropriate return type. The return statement sends the result back to the part of the program that called the method. 

static int AddMana(int a, int b){
    return a + b;
}
ARCANE FACT

Return values allow methods to perform calculations or processes while allowing another part of the program to use the resulting information.

LEARN THE SPELL • 06

void Methods

A method that does not return a value can use the void return type.

These methods are useful when the purpose of the method is simply to perform an action, such as displaying information.

void int string
A void method performs its task and then ends, without sending any value back.
LEARN THE SPELL • 07

Method Overloading

Method overloading allows multiple methods to have the same name while using different parameter lists.

This allows programmers to use one meaningful method name for related operations that require different types or numbers of inputs. 

static int AddMana(int a, int b){
    return a + b;
}

static double AddMana(double a, double b){
    return a + b;
}
LEARN THE SPELL • 08

Organizing Programs with Methods

Methods can make a program easier to read, test, and maintain because each method can focus on a particular task.

Breaking a large program into smaller methods also makes it easier to identify where a problem occurs when debugging.

TESTING & DEBUGGING

Well-organized methods make it easier to trace an issue back to the exact block of code responsible, rather than searching through an entire spellbook.

The Apprentice's Quick Codex

01 • C# Methods

Methods are named blocks of instructions that execute when they are called. They help reduce repeated code and allow programs to be divided into smaller, more manageable tasks.

02 • Method Parameters

Parameters allow information to be passed into a method. A method can have one parameter, multiple parameters, or none depending on what information it needs.

03 • Default Parameters

A parameter can be assigned a default value. If an argument is not provided when the method is called, the default value can be used instead.

04 • Return Values

Methods can send a result back to the part of the program that called them. The method's return type indicates what kind of value it produces.

05 • Named Arguments

Named arguments allow a programmer to specify which parameter receives a particular value when calling a method. This can make method calls clearer, especially when several parameters are involved.

06 • Method Overloading

Method overloading allows related methods to share a name as long as their parameter lists differ. The compiler determines which version should be used based on the arguments provided.
