LEARN THE SPELL • 01

Bringing the Concepts Together

Programming concepts become more useful when they are combined to solve a complete problem.

A structured C# program can use variables to store information, operators to process values, conditions to make decisions, loops to repeat instructions, methods to organize tasks, and arrays to manage groups of information.

ARCANE FACT

A single spell rarely wins the battle — it's the combination of spells that creates true magic.

LEARN THE SPELL • 02

Analyzing a Programming Problem

Before writing code, programmers should understand what the program needs to accomplish.

A problem can be examined by identifying:

01

What information is needed as input

02

What operations must be performed

03

What decisions must be made

04

What information should be repeated or stored

05

What results should be produced as output

Breaking the problem into smaller parts makes the programming task easier to manage.
LEARN THE SPELL • 03

Designing the Solution

An algorithm can be created to describe the sequence of steps required to solve the problem.

Pseudocode can then be used to describe the solution in a simple, language-independent form.

REMEMBER

A flowchart can also be used to visually represent the program's flow and identify processes, inputs, outputs, and decisions.

LEARN THE SPELL • 04

Using Variables and Operators

Variables can store the information needed by the program, while operators can process that information. 

int score1 = 90;
int score2 = 85;

int total = score1 + score2;
double average = total / 2.0;
A structured program may use variables to store scores and arithmetic operators to calculate a total or average.
LEARN THE SPELL • 05

Using Decisions and Loops

Conditions allow the program to respond differently depending on information or circumstances.

Loops allow repeated actions to be performed efficiently.

WORKING TOGETHER

Combining these structures allows programs to perform more complex tasks, such as repeatedly processing information while making decisions about each value.

LEARN THE SPELL • 06

Using Methods and Arrays

Methods can divide a large program into smaller tasks, while arrays can organize collections of related values.

ARCANE FACT

Together, these concepts allow programmers to create programs that are more organized and easier to maintain.

LEARN THE SPELL • 07

Testing and Debugging

A program should be tested after it has been written.

Testing involves checking whether the program produces the expected results for different inputs. When errors occur, debugging involves identifying the cause of the problem and making appropriate corrections.

Common problems may include syntax errors, incorrect logic, invalid input, or unexpected program behavior.
