LEARN THE SPELL • 01

Understanding Arrays

An array is a data structure that allows multiple values of the same data type to be stored under one variable name.

Without arrays, a programmer would need to create separate variables for every individual value. Arrays provide a more organized way to manage groups of related information.

ARCANE FACT

A program can use an array to store several scores, item prices, or character levels.

LEARN THE SPELL • 02

Declaring an Array

An array declaration specifies the type of values that the array will contain.

The square brackets [] indicate that the variable represents an array rather than a single value. 

int[] scores = { 90, 85, 78, 92 };
An array can be initialized with a group of values when it is created.
LEARN THE SPELL • 03

Array Indexing

Each element in an array has an index that identifies its position.

C# arrays use zero-based indexing, meaning the first element is located at index 0, the second at index 1, and so on. 

int[] scores = { 90, 85, 78, 92 };

Console.WriteLine(scores[0]);
// Output: 90
REMEMBER

Understanding indexes is important when accessing or modifying individual elements.

LEARN THE SPELL • 04

Accessing and Modifying Elements

A particular array element can be accessed using its index.

Values stored in an array can also be changed by assigning a new value to a specific position. 

scores[1] = 88;
This allows programs to update information without replacing the entire array.
LEARN THE SPELL • 05

Array Length

The number of elements an array contains can be determined using its Length property. 

Console.WriteLine(scores.Length);
// Output: 4
ARCANE FACT

Knowing the length of an array is especially useful when traversing its elements with loops.

LEARN THE SPELL • 06

Traversing an Array

Array traversal means going through the elements of an array one at a time. 

for(int i = 0; i < scores.Length; i++){
    Console.WriteLine(scores[i]);
}

foreach(int score in scores){
    Console.WriteLine(score);
}
A for loop can be used when the programmer needs access to the index of each element. A foreach loop can be used when the program simply needs to process each element in the collection.
LEARN THE SPELL • 07

Array Operations

Arrays can be processed using loops and built-in C# features.

Programs can search through arrays, sort their contents, calculate values from their elements, or perform other operations depending on the problem being solved.

LOOPS + ARRAYS

Understanding how arrays work together with loops is an important programming skill.

LEARN THE SPELL • 08

Multidimensional Arrays

A multidimensional array stores information across more than one dimension.

A two-dimensional array can be visualized as a table containing rows and columns. 

int[,] grid = {
    { 1, 2, 3 },
    { 4, 5, 6 }
};
Nested loops are commonly used to access and process the values stored in a multidimensional array.
