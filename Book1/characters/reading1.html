LEARN THE SPELL • 01

What is Programming?

Programming is the process of creating instructions that tell a computer what to do. These instructions are written using a programming language that computers can interpret and execute.

Before writing code, programmers usually identify the problem that needs to be solved and plan the steps needed to produce the desired result.

A Program Has Three Basic Components

01

Input The information provided to the program.

02

Process The operations performed on the information.

03

Output The result produced by the program.

EXAMPLE

A program that calculates a student's average may:

  1. Receive the student's scores as input.
  2. Calculate the average as the process.
  3. Display the average as the output.
LEARN THE SPELL • 02

What is C#?

C# (C-Sharp) is a modern, general-purpose programming language developed by Microsoft.

It is commonly used to create different types of applications, including desktop applications, web applications, games, and other software.

ARCANE FACT

C# works with the .NET platform, which provides tools and libraries that help developers build and run applications.

In this course, C# will be used to introduce fundamental programming concepts such as:

VARIABLES OPERATORS DECISION-MAKING LOOPS METHODS ARRAYS
LEARN THE SPELL • 03

Getting Started with C#

To write and execute a C# program, a programmer needs a development environment.

What is an IDE?

An Integrated Development Environment (IDE) provides tools for writing, editing, running, and debugging code.

Common C# development environments include:

VISUAL STUDIO Full-featured IDE
VISUAL STUDIO CODE Lightweight code editor

A basic C# program can display text using Console.WriteLine(). 

Console.WriteLine("Welcome to C#!");
The statement instructs the program to display the specified message in the console.
LEARN THE SPELL • 04

Understanding C# Program Structure

A C# program is made up of different elements that work together to perform a task.

01

Statements Instructions that tell the program what to do.

02

Braces { } Define blocks of code.

03

Semicolons ; Mark the end of most statements.

04

Methods Contain instructions that can be executed.

05

Comments Provide notes that help explain the code.

PROGRAM STRUCTURE • EXAMPLE

A Basic C# Program 

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, C#!");
    }
}

The Main() method serves as the starting point of a traditional C# console application.

The Console.WriteLine() statement displays text on the screen.

APPRENTICE NOTE

Modern C# project templates may look different because C# also supports top-level statements.

For introductory learning, both forms can be introduced depending on the development environment used.

LEARN THE SPELL • 05

C# Syntax

Syntax refers to the rules that determine how C# code must be written. 

Console.WriteLine("Hello!");
Console.WriteLine()

The command used to display output.

"Hello!"

The text being displayed.

;

Marks the end of the statement.

C# IS CASE-SENSITIVE

Uppercase and lowercase letters are treated differently. 

Console.WriteLine("Hello");

is different from:

console.writeline("Hello");
LEARN THE SPELL • 06

Planning a Program

Writing code is only one part of programming. Before implementing a solution, programmers can create a plan that describes how the problem will be solved.

01

Pseudocode

Pseudocode is a simplified, human-readable description of the steps a program should perform. 

START
Input user's name
Display user's name
END

Pseudocode allows programmers to focus on the logic of the solution before worrying about programming syntax.

PROGRAM PLANNING • 02

Flowcharts

A flowchart is a visual representation of the steps in an algorithm.

Oval Start / End

Parallelogram Input / Output

Rectangle Process

Diamond Decision

Arrows show the direction of flow from one step to another.
LEARN THE SPELL • 07

Understanding Sequential Flow

A sequential structure is a programming structure in which instructions are executed one after another in the order in which they appear.

SEQUENTIAL FLOW • EXAMPLE

Instructions Follow an Order 

Console.WriteLine("Enter the magical world.");
Console.WriteLine("Learn the ancient spells.");
Console.WriteLine("Begin your C# journey.");
01
↓
02
↓
03

The statements are executed from top to bottom.

REMEMBER

Understanding sequential execution is important because it serves as the foundation for more advanced structures such as decision structures and loops.
