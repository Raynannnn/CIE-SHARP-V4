01

Every Statement Ends With a Semicolon ( ; )

A statement is one complete instruction in C#. The semicolon tells the compiler "this instruction is finished." Forgetting it is the most common reason code fails to run. 

int age = 20;
Console.WriteLine("Hello World");
int score = 100;

💡 If you see a blank space where code should end — think semicolon first.

02

Code Has an Order: Declare → Open → Do → Close

A method is written in this order: its declaration (like static void Main()), then an opening brace { to start the body, the statements inside, then a closing brace } to end it. A variable must also exist before you can use it. 

static void Main()
{
    int score = 100;
    Console.WriteLine(score);
}

💡 You can't print a variable before it's created — "score" has to exist first.

03

Proper Formatting: Indent What's Inside the Braces

Anything inside { } should be indented so it's clear it belongs to that block. An if condition always needs parentheses ( ), and its statement still needs a semicolon. 

if (age >= 18)
{
    Console.WriteLine("Adult");
}

💡 Indentation isn't required to run the code — but it IS required in these trials to prove you understand structure.
