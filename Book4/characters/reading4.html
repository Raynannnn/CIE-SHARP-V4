LEARN THE SPELL • 01

Understanding Conditions

Programs often need to make decisions based on information or circumstances. A condition is an expression that evaluates to either true or false.

Conditions commonly use comparison operators such as >, <, ==, and !=.

ARCANE FACT

A program may check whether a player's level is high enough to enter a particular area.

LEARN THE SPELL • 02

The if Statement

The if statement allows a program to execute a block of code only when a specified condition is true.

It is useful when a program has an action that should occur only under a particular circumstance. 

int mana = 30;

if(mana >= 20){
    Console.WriteLine("Spell activated!");
}
The code inside the curly braces only runs when the condition evaluates to true.
LEARN THE SPELL • 03

The if-else Statement

An if-else structure provides two possible paths. If the condition is true, the if block is executed. If the condition is false, the else block is executed. 

if(mana >= 20){
    Console.WriteLine("Spell activated!");
}
else{
    Console.WriteLine("Not enough mana.");
}
REMEMBER

This allows a program to respond differently depending on the result of a condition.

LEARN THE SPELL • 04

The else-if Statement

Sometimes a program needs to evaluate more than two possibilities. The else if structure allows additional conditions to be checked when previous conditions are false. 

if(level >= 10){
    Console.WriteLine("Master Rank");
}
else if(level >= 5){
    Console.WriteLine("Adept Rank");
}
else{
    Console.WriteLine("Novice Rank");
}
Multiple else-if branches can be used when a program needs to classify information into different categories.
LEARN THE SPELL • 05

Nested Conditions

A conditional statement can be placed inside another conditional statement. This is known as a nested condition.

Nested conditions are useful when one decision depends on another decision.

WATCH YOUR NESTING

Excessive nesting can make a program harder to read, so conditions should be organized carefully.

LEARN THE SPELL • 06

The switch Statement

A switch statement provides another way to select an action based on a value. It is useful when a program needs to compare one expression against several possible cases.

case

Identifies a possible matching value.

break

Ends the selected case.

default

Provides an alternative when no case matches.

LEARN THE SPELL • 07

Combining Conditions

Logical operators can be combined with conditional statements to create more specific decisions.

For example, a program may require two conditions to be true before allowing an action to occur.

&& || !
Using &&, ||, and ! allows programmers to create conditions that represent more complex situations.
LEARN THE SPELL • 08

Short-Hand If...Else

C# also supports a shorter conditional expression for situations where a simple decision needs to produce one of two possible results. 

string result = (mana >= 20) ? "Cast" : "Blocked";
ARCANE FACT

This is known as the ternary operator — it evaluates a condition and returns one of two values in a single line.
