LEARN THE SPELL • 01

Understanding Loops

A loop is a programming structure that allows a block of instructions to be executed repeatedly.

Loops are useful when the same operation needs to be performed multiple times. Instead of writing the same statements repeatedly, a programmer can use a loop to control the repetition.

ARCANE FACT

A single loop can replace dozens of repeated lines of code with just a few lines of instructions.

LEARN THE SPELL • 02

The while Loop

A while loop repeatedly executes a block of code as long as its condition remains true.

The condition is checked before each iteration. If the condition is already false when the loop begins, the instructions inside the loop may not execute at all. 

int mana = 0;

while(mana < 5){
    Console.WriteLine("Gathering mana...");
    mana++;
}
A counter or another changing value is often used to eventually make the condition false.
LEARN THE SPELL • 03

The do-while Loop

The do-while loop is similar to a while loop, but the instructions are executed before the condition is checked. 

int mana = 0;

do{
    Console.WriteLine("Gathering mana...");
    mana++;
}
while(mana < 5);
REMEMBER

Because of this structure, the code inside a do-while loop executes at least once before the condition determines whether repetition should continue.

LEARN THE SPELL • 04

The for Loop

A for loop is useful when the number of repetitions is known or can be controlled through a counter.

A typical for loop contains three parts:

01

Initialization Establishes the starting value.

02

Condition Determines whether the loop continues.

03

Iteration Changes the counter after each repetition.

for(int i = 1; i <= 5; i++){
    Console.WriteLine("Strike " + i);
}
LEARN THE SPELL • 05

Loop Counters

A loop counter keeps track of how many times a loop has executed.

For example, a counter can begin at one and increase by one after each iteration. The loop can then stop once the counter reaches a specified value.

CONTROL YOUR COUNTER

Correctly controlling the counter is important for preventing unintended repetition.

LEARN THE SPELL • 06

Nested Loops

A loop can be placed inside another loop. This is called a nested loop.

Nested loops are useful for problems involving repeated groups of repetitions, such as working with rows and columns or processing multidimensional data. 

for(int row = 1; row <= 3; row++){
    for(int col = 1; col <= 3; col++){
        Console.WriteLine("Row " + row + ", Col " + col);
    }
}
LEARN THE SPELL • 07

break and continue

C# provides statements that can control how loops behave.

break

Immediately stops a loop.

continue

Skips the remaining instructions in the current iteration and proceeds to the next iteration.

These statements provide additional control when normal loop conditions are not enough.
LEARN THE SPELL • 08

The foreach Loop

A foreach loop can be used to process each element in a collection or array without manually managing an index counter. 

string[] spells = { "Fireball", "Heal", "Shield" };

foreach(string spell in spells){
    Console.WriteLine(spell);
}
ARCANE FACT

foreach automatically moves through every item in a collection, one at a time, until none remain.

The Apprentice's Quick Codex

01 • C# While Loop

A while loop repeats instructions while its condition evaluates to true. The condition is checked before each repetition, meaning the loop may execute zero or more times.

02 • C# Do/While Loop

A do-while loop executes its instructions before checking the condition. As a result, the loop body runs at least once.

03 • C# For Loop

A for loop combines initialization, a condition, and an iteration expression in one structure. It is particularly useful when repetition can be controlled with a counter.

04 • C# Foreach Loop

A foreach loop can be used to process each element in a collection or array without manually managing an index counter.

05 • C# Break and Continue

The break statement ends a loop immediately, while continue moves the program to the next iteration. These statements can provide additional control over repeated execution.

06 • Nested Loops

A loop can contain another loop. The inner loop completes its repetitions for each iteration of the outer loop.
