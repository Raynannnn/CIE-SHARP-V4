Understanding Variables

Variables are named storage locations used by a program to keep information that may be needed during execution. A variable can hold a value such as a number, a character, text, or a Boolean value.

Variables make programs more flexible because their stored values can be used, displayed, or changed while the program runs.

ARCANE FACT

A variable can be thought of as a labeled container that holds a particular value.

EXAMPLE

A program may use variables to store:

  1. A character's name
  2. A character's level
  3. A character's health points
  4. The amount of mana
LEARN THE SPELL • 02

Declaring a Variable

Before using a variable, the programmer needs to specify its data type and give it a name. The general structure is: 

dataType variableName;

For example: 

int playerLevel;

What Does This Do?

This statement declares a variable named playerLevel that is intended to store an integer. Declaring a variable tells C# what kind of information the variable is designed to hold.

LEARN THE SPELL • 03

Initializing and Assigning Variables

A variable can be given a value when it is declared. This is called initialization. 

int playerLevel = 10;

A variable can also be declared first and assigned a value later. 

int playerLevel;
playerLevel = 10;
REMEMBER

Once a variable has been assigned a value, that value can be used in other parts of the program. Variables can also receive new values — when a new value is assigned, the previous value is replaced.

LEARN THE SPELL • 04

Common C# Data Types

A data type determines the kind of value that a variable can store. Choosing the appropriate data type helps the program handle information correctly.

int double float decimal char string bool
01

int Stores whole numbers.

02

double / float / decimal Store numbers with decimal values. Decimal is commonly used when greater precision is needed.

03

char Stores a single character.

04

string Stores text.

05

bool Stores either true or false.

LEARN THE SPELL • 05

Identifiers & Naming Conventions

The name given to a variable is called an identifier. A good variable name should describe the information it stores. 

int playerLevel = 10;

is easier to understand than: 

int x = 10;
C# NAMING RULES

Variable names should not contain spaces or use reserved C# keywords, and capitalization matters because C# is case-sensitive.

Using meaningful names makes programs easier to read, understand, and maintain.
LEARN THE SPELL • 06

Constants

Some values should remain unchanged throughout a program. C# allows programmers to define these values as constants using the const keyword. 

const int maxLevel = 100;

One Rule to Remember

A constant must be given a value when it is declared and cannot later be changed.

Constants are useful for information that should remain fixed, such as a maximum level, a conversion value, or another fixed value used by a program.
LEARN THE SPELL • 07

Displaying Variable Values

Variables can be displayed using Console.WriteLine(). A program can also combine text and variable values when producing output. 

int playerLevel = 10;
Console.WriteLine(playerLevel);
ARCANE FACT

This allows programs to display information that changes depending on the values currently stored in the variables — such as a player's name or current level — instead of displaying the same message every time.

LEARN THE SPELL • 08

Receiving User Input

Programs can become more interactive by allowing users to enter information. C# provides Console.ReadLine() for receiving input from the console. 

Console.WriteLine("Enter your name:");
string playerName = Console.ReadLine();
INPUT IS RECEIVED AS TEXT

Information entered by the user is initially received as text, so numerical input may need to be converted to the appropriate numeric data type before it can be used in calculations.

This allows a program to receive information such as a user's name, age, score, or other values while the program is running.
