LEARN THE SPELL • 01

Understanding File Input and Output

Programs sometimes need to store information so that it can be accessed again after the program has finished running.

File input/output (File I/O) allows programs to interact with files stored on a computer.

ARCANE FACT

A program can read information from a file or write new information into a file.

LEARN THE SPELL • 02

Working with Files

C# provides classes and methods that allow programs to work with files.

The System.IO namespace contains features commonly used for file operations.

The File class provides methods for creating, reading, writing, copying, deleting, and checking files.
LEARN THE SPELL • 03

Creating and Writing Files

A program can create a new file and store information inside it.

Writing information to a file allows data to be preserved beyond the current execution of a program.

REPLACE OR APPEND?

When writing to an existing file, programmers should understand whether the operation will replace existing content or add information to it.

LEARN THE SPELL • 04

Reading Files

Programs can read information stored in a file and use that information during execution.

REMEMBER

Reading a file can be useful for retrieving saved data, displaying stored information, or processing information that was created previously.

LEARN THE SPELL • 05

Checking and Managing Files

Before performing an operation, a program may need to determine whether a file exists.

C# provides file-handling features that can help programs check files and perform operations such as copying, moving, deleting, or replacing them.

Proper file management helps prevent unexpected errors.
LEARN THE SPELL • 06

Handling File-Related Errors

File operations may encounter problems, such as attempting to access a file that does not exist or using an invalid location.

C# provides exception handling through structures such as try, catch, and finally. 

try{
    // risky file operation
}
catch(Exception e){
    Console.WriteLine("Error: " + e.Message);
}
Exception handling allows a program to respond to certain runtime problems instead of terminating unexpectedly.

01 • C# Files

C# provides file-handling features through the System.IO namespace. The File class includes methods for common operations such as creating, reading, writing, copying, deleting, and checking files.

02 • Writing to Files

Programs can save information into a file using file-writing methods. Writing can create a new file or replace existing content depending on the operation being used.

03 • Reading from Files

Programs can retrieve stored information from a file and use the retrieved content during execution. This allows information to be preserved and accessed later.

04 • Checking Files

Programs can check whether a file exists before attempting to access it. This can help reduce errors during file operations.

05 • C# Exceptions

Exceptions are runtime problems that can occur while a program is executing. C# provides exception-handling structures such as try, catch, and finally to allow programs to respond to errors in a controlled manner.
