LEARN THE SPELL • 01

Understanding Operators

Operators are symbols used to perform actions on values and variables. They allow programs to calculate results, compare information, assign values, and evaluate conditions.

An expression is created when values, variables, and operators are combined to produce a result.

ARCANE FACT

An arithmetic expression can calculate the total amount of mana available to a character.

LEARN THE SPELL • 02

Arithmetic Operators

Arithmetic operators are used to perform mathematical operations. The commonly used arithmetic operators in C# are:

+

Addition Adds two values together.

-

Subtraction Subtracts one value from another.

*

Multiplication Multiplies two values.

/

Division Divides one value by another.

%

Modulus Returns the remainder of a division.

++

Increment Increases a value by 1.

--

Decrement Decreases a value by 1.

These operators allow programs to perform calculations using numeric values.
LEARN THE SPELL • 03

Assignment Operators

Assignment operators are used to place values into variables. The basic assignment operator is =.

C# also provides shortened forms for modifying existing values:

+= -= *= /= %= 
int mana = 50;
mana += 20;

The line above is the same as writing mana = mana + 20;

These operators make it possible to update variables without repeatedly writing the entire expression.
LEARN THE SPELL • 04

Comparison Operators

Comparison operators determine the relationship between two values.

==

Equal to

!=

Not equal to

>

Greater than

<

Less than

>=

Greater than or equal to

<=

Less than or equal to

REMEMBER

The result of a comparison is always a Boolean value: either true or false.

LEARN THE SPELL • 05

Logical Operators

Logical operators allow multiple conditions to be combined.

&&

AND Requires both conditions to be true.

||

OR Produces a true result when at least one condition is true.

!

NOT Reverses a Boolean result.

LEARN THE SPELL • 06

Boolean Values

A Boolean value represents one of two possible states:

true false
ARCANE FACT

Boolean values are especially important when programs need to evaluate conditions. They are commonly used together with comparison and logical operators to determine what a program should do.

LEARN THE SPELL • 07

Expressions and Evaluation

An expression combines values, variables, and operators to produce a result.

For example, an arithmetic expression may calculate a character's remaining health, while a comparison expression may determine whether that health is below a certain value.

OPERATOR PRECEDENCE

When multiple operators appear in an expression, C# follows rules of operator precedence to determine the order in which operations are performed. Understanding these rules helps programmers predict the result of an expression.

LEARN THE SPELL • 08

Mathematical Operations

C# provides the Math class for performing additional mathematical operations.

It can be used for tasks such as finding powers, square roots, absolute values, and other mathematical results.

These functions become useful when programs require calculations beyond basic arithmetic operators.
